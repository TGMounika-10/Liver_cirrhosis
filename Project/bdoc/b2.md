# bmod2-report-parser

**Purpose:** Extract lab values from uploaded PDF or image reports.

## Pipeline
1. **Check file:** extension, MIME type, magic bytes, and size limit; reject anything else.
2. **PDF:** text extraction with `pdfplumber` (or PyMuPDF). If a page has no text layer, render it to an image and OCR it.
3. **Image:** pre-process (grayscale, resize, threshold) then OCR with Tesseract (`pytesseract`).
4. **Find values:** regex and synonym table, e.g. `SGPT`, `ALT`, `Alanine Aminotransferase` all map to `sgpt`; handle formats like `2.4 mg/dL` or `Total Bilirubin : 2.4`.
5. **Normalize units** where possible (e.g. bilirubin µmol/L to mg/dL, albumin g/L to g/dL) and record any conversion in `warnings`.
6. Return structured JSON with `requires_confirmation: true`.

## Output
```json
{
  "status": "success",
  "extracted_values": { "total_bilirubin": 2.4, "albumin": 2.9 },
  "missing": ["ag_ratio"],
  "warnings": ["Albumin converted from g/L to g/dL"],
  "requires_confirmation": true
}
```

## Rules
- **Never** send unverified OCR output to the ML model; the user must confirm it in the frontend first.
- Process files in memory or a temp folder and delete them immediately; do not keep raw reports.
- Do not extract or return patient name, address, or other identifiers.
- If a value is ambiguous (two matches), leave it empty and add a warning instead of guessing.

## Suggested files
`parser.py`, `pdf_reader.py`, `ocr.py`, `extractors.py`, `synonyms.py`, `units.py`

## Done when
- Sample reports in `data/reports_samples/` produce expected values in unit tests.
- Unreadable files return a clear `REPORT_UNREADABLE` error.

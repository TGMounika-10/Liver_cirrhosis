# bmod1-api-core

**Purpose:** FastAPI application entry point: routing, configuration, CORS, logging, and error handling.

## Endpoints
| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| POST | `/api/auth/signup` | Public | Create account (bmod6) |
| POST | `/api/auth/login` | Public | Get access token (bmod6) |
| GET | `/api/auth/me` | Token | Current Patient ID (bmod6) |
| POST | `/api/report/upload` | Token | Upload report, return extracted values (bmod2) |
| POST | `/api/predict/manual` | Token | Validate values, return risk (bmod3 + bmod4 + bmod5) |
| GET | `/api/model/info` | Public | Metrics and model metadata |
| GET | `/api/health` | Public | Liveness check |

## Responsibilities
- Create the app, include routers, and load the ML model and scaler **once at startup** (lifespan event).
- Settings from `.env` using Pydantic Settings: `MODEL_PATH`, `SCALER_PATH`, `SECRET_KEY`, `DATABASE_URL`, `ALLOWED_ORIGINS`, `MAX_UPLOAD_MB`.
- CORS: allow only the React frontend origin(s) from `ALLOWED_ORIGINS`.
- Pydantic request/response schemas for every endpoint.
- Structured errors for everything: `{ "status": "error", "code": "VALIDATION_ERROR", "message": "...", "fields": {...} }`.
- Logging of technical events (route, status, duration). **No Patient IDs, passwords, tokens, or lab values in logs.**

## Suggested files
`main.py`, `config.py`, `deps.py` (auth dependency), `errors.py`, `schemas.py`, `logging_config.py`

## Done when
- `/api/health` returns 200 without loading anything heavy.
- Calling a protected route without a token returns 401 in the standard error shape.
- Unhandled exceptions return a generic 500 without stack traces.

# bmod5-explainability

**Purpose:** Explain why the model produced a given result, in plain language.

## Responsibilities
- Compute feature contributions with SHAP (tree models), model coefficients (logistic regression), or permutation importance as a fallback.
- Return the **top 3 to 5** features that pushed the estimate up or down.
- Translate each into a simple sentence using a template table, e.g.
  - "Low albumin increased the estimated risk."
  - "High total bilirubin increased the estimated risk."
  - "Normal ALP slightly lowered the estimated risk."
- Return `top_factors: [{ feature, impact, message }]`.

## Rules
- Use wording like "contributed to the estimate", never "caused" or "proves".
- Do not present gender or age as a medical reason; if they rank highly, show a neutral note.
- If contributions are very small or unstable, say "No single factor stood out" instead of forcing a list.
- Include a note that explanations describe the model, not the patient's biology.
- Check that top features are medically plausible during validation.

## Suggested files
`explain.py`, `messages.py`, `shap_utils.py`

## Done when
- Every feature in the model has a message template.
- Explanations never exceed 5 items and match the direction of the model output.

# fmod4-result-dashboard

**Purpose:** Show the prediction clearly and responsibly.

## Sections
1. **Risk summary:** category (Low / Moderate / High) and probability, worded "Model-estimated liver disease/cirrhosis risk: 78%". Never "You have cirrhosis."
2. **Risk gauge** (semi-circle or progress bar) coloured green / amber / red by category.
3. **Marker table:** every submitted value with a status chip: Normal (green), Borderline (amber), Abnormal (red), plus the reference range.
4. **Top contributing factors:** 3 to 5 plain-language lines from `top_factors`, e.g. "Low albumin increased the estimated risk."
5. **Next steps card:** prominent "Consult a qualified doctor" message; shown for every category, most prominent for Moderate and High.
6. **Limitations and disclaimer:** always visible, not collapsed.
7. Actions: Start new check, Print / save summary (summary excludes the uploaded file).

## Components
`RiskSummary`, `RiskGauge`, `MarkerTable`, `FactorList`, `NextStepsCard`, `DisclaimerBlock`

## Rules
- Confidence is a probability, never certainty. Avoid "positive/negative" or "confirmed".
- Red only for High risk and abnormal markers; accessible contrast for all chips (colour is never the only signal; chips also carry text).
- If the page is opened with no result in state, redirect to `/manual`.

## Done when
- Low, Moderate, and High sample responses each render with the correct colour and wording.
- Disclaimer and limitations are visible without any extra click.

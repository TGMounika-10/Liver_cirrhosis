# fmod5-model-info

**Purpose:** Transparency about the data, the model, its metrics, and its limits.

## Content (loaded from `GET /api/model/info`)
- Dataset source (e.g. ILPD) and number of records.
- Model type, training date, model version.
- Accuracy, precision, recall, F1-score, ROC-AUC (cards with one-line explanations).
- Confusion matrix (grid with TP / FP / TN / FN labelled).
- Class balance chart (liver disease vs no liver disease).
- Subgroup performance by gender and age band.
- Known limitations and a statement that the tool is **not a diagnostic device**.

## Components
`MetricCards`, `ConfusionMatrix`, `ClassBalanceChart`, `SubgroupTable`, `LimitationsList` (Recharts or Chart.js)

## Rules
- Show metrics exactly as stored in `models/metrics.json`; never round up or hide weak ones.
- Show a friendly error with retry if the endpoint fails.
- Page is public so people can read about the model before signing up.

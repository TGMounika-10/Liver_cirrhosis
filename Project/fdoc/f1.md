# fmod1-app-shell

**Purpose:** Base React application: routing, global layout, theme, header, footer, medical disclaimer, and route protection.

## Pages and routes
| Route | Page | Access |
| --- | --- | --- |
| `/` | Home / Awareness (fmod7) | Public |
| `/login`, `/signup` | Auth pages (fmod6) | Public (redirect to `/upload` if already logged in) |
| `/upload` | Upload Report (fmod2) | Login required |
| `/manual` | Manual Entry (fmod3) | Login required |
| `/result` | Result Dashboard (fmod4) | Login required |
| `/about-model` | About Model (fmod5) | Public |

## Responsibilities
- React Router setup with a `ProtectedRoute` wrapper that redirects unauthenticated users to `/login` and returns them to the page they asked for after login.
- Header: logo, nav links (Home, Upload, Manual Entry, About Model), and either **Login / Sign up** buttons or the signed-in **Patient ID + Logout**.
- Footer with a short disclaimer and a link to About Model.
- Global medical disclaimer banner (dismissible on Home, always visible on result screens).
- Theme tokens as CSS variables: `--blue #1565C0`, `--red #C62828`, `--amber #F9A825`, `--green #2E7D32`, `--bg #F7F9FC`, `--surface #FFFFFF`, `--text #1F2937`.
- Environment-based API URL via `VITE_API_BASE_URL`; one shared Axios instance that attaches the auth token and handles `401` by logging the user out.

## Suggested files
`App.jsx`, `routes.jsx`, `ProtectedRoute.jsx`, `Header.jsx`, `Footer.jsx`, `DisclaimerBanner.jsx`, `theme.css`, `api/client.js`

## Rules
- Red is an accent only; never a full-screen background.
- All colour pairs meet WCAG AA contrast; keyboard focus is always visible.
- API base URL is never hard-coded.

## Done when
- Unauthenticated access to `/upload`, `/manual`, `/result` redirects to login.
- Disclaimer is visible on every result screen.
- Layout works from 360 px phone width upward.
